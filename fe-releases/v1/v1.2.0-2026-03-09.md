## <span id="전화번호-포맷팅-수정">📋 전화번호 포맷팅 수정</span>

### 설명

병원 등록·수정 시 전화번호 포맷팅을 수정했습니다. 저장한 값이 UI에 그대로 보이도록 했습니다. 또한 전화번호 필드에 입력 검증을 추가해, 하이픈(-)을 제외하면 숫자만 입력할 수 있고 한글·특수문자는 저장되지 않습니다.

### 예제

<img width="2367" height="1066" alt="image" src="https://github.com/user-attachments/assets/f23dc813-1630-430d-a0cc-aa579a18b5ae" />

`010-1234-5678`처럼 입력하면 그대로 보이고, `02-123456-1234`처럼 입력해도 그대로 표시됩니다. 이전에 02 번호가 잘못 표시되던 현상이 해결되었습니다. 한글이나 숫자·하이픈이 아닌 문자를 넣으면 저장 시 '전화번호는 숫자와 하이픈(-)만 입력할 수 있습니다' 안내가 표시됩니다.

## <span id="키워드-입력-엔터-이동-개선">📋 키워드 입력 엔터 이동 개선</span>

### 설명

키워드 기획 입력 행에서 `Enter` 키 이동 규칙을 개선했습니다. 같은 열에서는 아래 행으로 순서대로 이동하고, 마지막 행에 도달하면 다음 열의 첫 행으로 이어서 이동해 연속 입력이 더 자연스러워졌습니다.

### 사용 방법

1. 키워드 기획 입력 행을 여러 개 추가합니다.
2. 같은 열에서 `Enter`를 눌러 아래 행으로 이동합니다.
3. 마지막 행에서 다시 `Enter`를 누르면 다음 열의 첫 행으로 이동합니다.

### 예제

<img width="1859" height="294" alt="image" src="https://github.com/user-attachments/assets/b34c24ae-3c91-445c-bee4-445cd64afd70" />

예를 들어 `1-1 -> 2-1 -> 3-1` 순서로 입력하다가 마지막 행인 `3-1`에서 `Enter`를 누르면 `1-2`로 이동합니다. 여러 행을 빠르게 입력할 때 마우스 없이 열 단위로 이어서 작업할 수 있습니다.

## <span id="키워드-기획-기본-연월-다음달-설정">📋 키워드 기획 기본 연월 다음달 설정</span>

### 설명

키워드 기획과 외주 키워드 기획 화면의 기본 연월을 다음 달로 보이도록 수정했습니다. 월별 작업을 미리 준비하는 흐름에 맞춰, 페이지 진입 시 이번 달이 아니라 다음 달 기준으로 바로 확인하고 입력할 수 있습니다.

### 사용 방법

1. `키워드 기획` 또는 `외주 키워드 기획` 페이지로 이동합니다.
2. 페이지 진입 시 상단 연월 선택값이 다음 달로 기본 설정되어 있는지 확인합니다.
3. 필요하면 기존처럼 다른 연월로 직접 변경해 사용합니다.

### 예제

<img width="2487" height="214" alt="image" src="https://github.com/user-attachments/assets/94a2667a-9567-4078-840d-72643b856084" />

3월에 페이지에 접속하면 기본 선택값이 4월로 표시됩니다. 사용자는 매번 연월을 바꾸지 않고도 다음 달 작업을 바로 시작할 수 있습니다.

## <span id="외주-키워드-메모">📋 외주 키워드 메모</span>

### 설명

병원별 외주 키워드 메모를 조회하고 저장할 수 있는 메모 패널을 추가했습니다. 저장 후에는 목록 데이터에 바로 반영되도록 처리해, 새로고침 없이 최신 메모를 확인할 수 있습니다.

### 사용 방법

1. `외주 키워드 기획` 페이지에서 원하는 병원 영역을 확인
2. 우측 메모 패널에서 메모를 입력하거나 수정
3. 저장 버튼을 눌러 병원별 외주 키워드 메모를 반영

## <span id="키워드-입력-줄바꿈-개선">📋 키워드 입력 줄바꿈 개선</span>

### 설명

키워드 입력 행에서 `Shift + Enter`로 줄바꿈할 수 있도록 기능을 추가했습니다.

### 사용 방법

1. 키워드 입력 셀을 편집 모드로 엽니다.
2. 줄바꿈이 필요한 위치에서 `Shift + Enter`를 입력합니다.
3. 입력 시 윗줄로 이동합니다.

## <span id="외부-작가-접근-제어">📋 외부 작가 접근 제어</span>

### 설명

외부 작가 계정을 위한 전용 role과 접근 제한 규칙을 추가했습니다. 외부 작가 계정은 허용된 메뉴와 경로만 볼 수 있도록 사이드바와 라우팅 가드를 함께 적용했습니다.

### 사용 방법

1. 외부 작가 계정으로 로그인
2. 사이드바에서 허용된 메뉴만 노출되는지 확인
3. 허용되지 않은 경로로 직접 접근 시 외주 키워드 기획 페이지로 이동되는지 확인

### 예제

외부 작가 계정은 `외주 키워드 기획` 화면만 접근할 수 있고, 다른 관리 화면 URL을 직접 입력해도 전용 페이지로 유도됩니다.

## <span id="엑셀-테이블-html-복사">📋 엑셀 테이블 HTML 복사</span>

### 설명

엑셀 파일을 업로드하면 빈 행을 기준으로 시트가 여러 테이블로 나뉘고, 각 테이블을 미리보기한 뒤 전체를 HTML 마크업으로 클립보드에 복사할 수 있는 기능이 추가되었습니다. 복사된 HTML은 스타일 없이 `<table>`, `<tbody>`, `<tr>`, `<td>`와 병합 정보(`rowspan`, `colspan`)만 포함하여, 에디터나 문서에 붙여넣기 시 해당 환경의 기본 스타일이 적용됩니다.

### 사용 방법

1. 홈페이지에서 엑셀 테이블 복사 페이지로 이동
2. 엑셀 파일(.xlsx)을 드롭 영역에 업로드
3. 빈 행으로 구분된 테이블 블록들이 미리보기로 표시됨
4. "전체 클립보드에 HTML로 복사" 버튼 클릭
5. 원하는 에디터/문서에 붙여넣기

### 예제

엑셀 파일을 업로드하면 테이블 단위로 미리보기가 되며, 복사 버튼으로 HTML이 클립보드에 저장됩니다. 붙여넣기 시 테이블 구조(행·열·병합)가 유지된 채로 적용됩니다.

## <span id="페이지-리팩토링">📋 페이지 리팩토링</span>

### 설명

관리(admin), 자동화(automation), 병원(hospital) 등 앱 전반의 페이지 구조를 리팩토링했습니다. 각 페이지의 UI를 페이지 전용 콘텐츠 컴포넌트(예: AdminPageContent, KeywordPlanningPageContent, KarrotUploadDetailsPageContent)로 분리하고, 레이아웃·타입(layout.types, page 콘텐츠 타입)을 정리했습니다. 테이블(Table) 및 관련 컨텍스트의 타입(TableProps, TableContextValue 등)을 보강하여 유지보수성과 타입 안정성을 높였습니다.

### 사용 방법

1. 기존과 동일하게 해당 메뉴에서 페이지 접근
2. 동작·UI는 동일하며, 내부 구조만 개선된 상태로 사용

### 예제

키워드 기획, 네이버 블로그, 당근 업로드 상세 등 페이지가 동일한 레이아웃과 네비게이션 아래에서 더 명확한 컴포넌트 구조로 동작합니다.
