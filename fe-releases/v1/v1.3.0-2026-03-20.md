## Summary of Changes

이번 릴리스에서 추가·변경된 주요 내용입니다.

| 구분                                     | 내용                                                                                      |
| :--------------------------------------- | :---------------------------------------------------------------------------------------- |
| **키워드 기획 메모 기능 복원**           | 키워드/주제 입력 화면과 목록 카드에 메모 칸을 다시 제공하고, 저장·복사에도 함께 반영      |
| **콘텐츠 플랜(키워드) 항목 삭제**        | 병원 상세·키워드 기획 화면에서 항목별 삭제 버튼 제공, 확인 팝업 후 삭제                   |
| **관리자 페이지 패키지·항목 관리**       | 관리자 설정에서 패키지와 패키지 항목 타입을 추가/수정/삭제할 수 있도록 개선               |
| **키워드 블로그 자동 입력(백엔드 연동)** | 등록한 키워드를 기준으로 블로그 글을 찾아 자동으로 입력·저장하는 기능 추가(사용자 안내용) |
| **페이지 이동 속도 개선**                | 메뉴 이동 때마다 반복되던 전체 로딩을 줄여 화면 전환이 더 빠르고 부드럽게 보이도록 개선   |
| **확인 팝업(ConfirmModal)**              | 삭제/변경 전 확인 창을 공통으로 사용해 실수 방지, 버튼 문구·강조 형태를 상황에 맞게 표시  |
| **병원 추가 시 패키지 선택 개선**        | 같은 패키지명이 여러 번 보여 혼란스럽던 문제를 정리해 목록이 깔끔하게 보이도록 수정       |
| **사이드바 축소 시 메뉴 미리보기**       | 사이드바를 접은 상태에서 아이콘에 마우스를 올리면 메뉴 이름/하위 메뉴가 옆에 표시됨       |
| **작은 화면에서 사이드바 자동 축소**     | 화면이 좁아지면 사이드바가 자동으로 접혀 본문을 더 넓게 볼 수 있도록 변경                 |
| **스토리북 스테이징 전용 배포**          | amplify.yml: prod는 Next만 빌드, 스테이징에서만 스토리북 빌드 후 `/storybook`로 제공      |
| **기획/컨펌 상태 표시 개선**             | 콘텐츠 플랜에서 컨펌예정·컨펌요청·컨펌완료일 때 기획 Select에 "기획완료"로 표시           |
| **스토리북 빌드 안정화**                 | Loading 스토리 variant 타입 수정(neutral→info)으로 Next 빌드·타입 체크 통과               |

| **인원별 담당 병원 수 표시**             | 키워드 기획 필터에서 선택한 팀원별 담당 병원 수를 필터 바에 표시 (추가 API 없음)          |
| **스토리북**                             | UI 컴포넌트 카탈로그를 스토리북으로 제공 (스테이징 환경에서 확인 가능)                    |

## <span id="키워드-기획-메모-기능-복원">📋 키워드 기획 메모 기능 복원 (작가팀)</span>

### 설명

이전에 빠졌던 **키워드 기획 메모** 기능을 다시 넣었습니다. 이제 입력 화면, 목록 화면, 카드 화면에서 메모를 적고 수정할 수 있고, 키워드 기획, 외주 키워드 기획, 병원 상세 화면에 동일하게 적용됩니다.

### 사용 방법

1. 키워드 기획 또는 병원 상세 콘텐츠 채널에서 포스트 기획 추가/수정 화면으로 이동합니다.
2. 입력 행에 **키워드**, **주제** 옆 **메모 (선택사항)** 칸에 내용을 입력할 수 있습니다.
3. 테이블에서 수정 시에도 메모 컬럼을 편집할 수 있고, 아이템 카드에 메모가 있으면 표시됩니다.

## <span id="콘텐츠-플랜키워드-아이템-삭제">📋 콘텐츠 플랜(키워드) 아이템 삭제</span>

### 설명

병원 상세 화면과 키워드 기획 화면에서 **키워드/주제 항목을 삭제**할 수 있게 했습니다. 각 행의 삭제 버튼을 누르면 확인 팝업이 뜨고, 확인하면 해당 항목이 목록에서 바로 사라집니다.

### 사용 방법

1. 병원 상세 → 콘텐츠 채널 탭 또는 키워드 기획 페이지에서 해당 연월·채널의 플랜을 엽니다.
2. 삭제할 기획 아이템 행의 **삭제** 버튼을 클릭합니다.
3. 확인 모달에서 **확인**을 누르면 삭제되고, **취소**를 누르면 모달만 닫힙니다.

## <span id="어드민-페이지-패키지패키지-항목-타입-추가수정삭제">📋 어드민 페이지 패키지·패키지 항목 타입 추가/수정/삭제</span>

### 설명

**관리자 설정** 페이지에서 **패키지**와 **패키지 항목 타입**을 추가·수정·삭제할 수 있는 기능을 추가했습니다. 패키지 탭에서는 패키지 목록 조회, 신규 생성(사이드 패널), 행 클릭 시 수정(사이드 패널), 삭제가 가능하고, 패키지 항목 타입 탭에서는 항목 타입(예: 네이버 블로그 수, 하이닥 수 등) 목록 조회, 신규 생성, 수정, 삭제가 가능합니다.

### 사용 방법

1. 사이드바에서 **관리자 설정** 메뉴로 이동합니다.
2. **패키지** 탭: 패키지 목록 확인, **추가** 버튼으로 신규 패키지 생성, 행 클릭으로 수정, 삭제 버튼으로 삭제합니다.
3. **패키지 항목 타입** 탭: 항목 타입 목록 확인, **추가** 버튼으로 신규 타입 생성, 행 클릭으로 수정, 삭제 버튼으로 삭제합니다.

## <span id="페이지-간-이동-성능-개선">📋 페이지 간 이동 성능 개선</span>

### 설명

페이지를 옮길 때마다 전체 로딩이 자주 보이던 부분을 줄였습니다. 이제 메뉴를 연속으로 이동해도 화면이 덜 끊기고 더 빠르게 넘어갑니다.

### 사용 방법

2. 페이지 전환 중 불필요한 전체 로딩 노출이 줄었는지 확인합니다.

## <span id="전역-확인-모달-confirmmodal">📋 전역 확인 모달 (ConfirmModal)</span>

### 설명

삭제/변경처럼 실수하면 곤란한 작업에 공통으로 쓰는 **확인 팝업**을 추가했습니다. 어디서 띄워도 같은 형태로 보여서 사용성이 일정하고, 확인/취소 버튼으로 안전하게 작업을 진행할 수 있습니다.

### 사용 방법

1. 삭제처럼 확인이 필요한 작업을 누르면 확인 팝업이 열립니다.
2. 팝업에서 `확인`을 누르면 작업이 진행되고, `취소`를 누르면 닫힙니다.
3. 경고가 필요한 경우에는 더 눈에 띄는 강조 형태로 안내됩니다.

## <span id="사이드바-축소-시-메뉴-호버-플라이아웃">📋 사이드바 축소 시 메뉴 호버 플라이아웃</span>

2. 메뉴 아이콘 위에 마우스를 올리면 옆에 메뉴명·하위 메뉴가 펼쳐집니다.
3. 원하는 메뉴를 클릭해 이동합니다.

### 사용 방법

1. 브라우저 창 너비를 xl 이하로 줄이면(또는 해당 해상도 디바이스에서) 사이드바가 자동으로 축소됩니다.
2. 다시 넓히면 이전에 사용자가 선택한 펼침/축소 상태가 유지됩니다(저장된 설정 기준).

## <span id="기획컨펌-상태-표시-개선">📋 기획/컨펌 상태 표시 개선</span>

### 설명

병원·콘텐츠 채널 상세의 콘텐츠 플랜에서, **기획 상태**와 **컨펌 상태**를 나란히 보여주는 Select가 있습니다. 실제 플랜 상태가 **컨펌예정**, **컨펌요청**, **컨펌완료** 중 하나일 때, 왼쪽 기획 상태 Select에는 "기획예정"이 아닌 **"기획완료"**로 표시되도록 수정했습니다. 컨펌 단계로 넘어간 경우 기획이 완료된 상태로 보이도록 하기 위함입니다.

### 사용 방법

1. 콘텐츠 채널·병원 상세에서 해당 연월의 플랜이 컨펌예정/컨펌요청/컨펌완료인 경우를 엽니다.
2. 상단의 기획·컨펌 상태 Select에서 왼쪽 드롭다운이 "기획완료"로 표시되는지 확인합니다.

## <span id="키워드-입력-빈-행-필터링-개선">📋 키워드 입력 빈 행 필터링 개선</span>

### 설명

키워드 기획과 외주 키워드 기획에서 `모두 저장` 시 입력 행 필터링 조건을 수정했습니다. 이제 키워드와 주제가 둘 다 비어있는 행만 제외하고, 둘 중 하나라도 입력된 행은 저장되도록 동작합니다.

### 사용 방법

1. `키워드 기획` 또는 `외주 키워드 기획` 화면에서 입력 행을 추가합니다.
2. 키워드만 입력하거나, 주제만 입력한 행을 포함해 내용을 작성합니다.
3. `모두 저장`을 눌러 둘 다 비어있는 행만 제외되고 나머지 행이 저장되는지 확인합니다.

## <span id="인원별-담당-병원-수-표시">📋 인원별 담당 병원 수 표시</span>

### 설명

키워드 기획 페이지 상단에서 팀원을 선택하면, 각 팀원이 담당하는 병원 수를 바로 볼 수 있습니다. 한 명을 선택하면 해당 인원 수만 보이고, 여러 명을 선택하면 각 인원별 수가 함께 표시됩니다. 외주 키워드 기획 페이지에는 이 안내가 표시되지 않습니다.

### 사용 방법

1. `키워드 기획` 페이지로 이동합니다.
2. 팀 필터에서 작가팀을 선택한 뒤, 팀원을 한 명 이상 체크합니다.
3. 필터 바 하단에 선택한 인원별 담당 병원 수가 표시되는지 확인합니다.
