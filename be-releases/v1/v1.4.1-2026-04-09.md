## v1.4.1 상세

### <span id="채널-발행-보고-crud">📋 채널 발행 보고 CRUD</span>

**설명**
9개 채널(카페 게시글, 카페 댓글, 체험단, 하이닥, 인스타 카드뉴스, 인스타 릴스, 당근, 지식인, 뉴스기사)별 발행 보고 CRUD API를 추가했습니다. 각 모듈은 CQRS 복잡 도메인 구조로 구현되었으며, MarketingTeamGuard로 접근 제어됩니다.

**사용 방법**
1. POST /v1/{channel-name} — 발행 보고 생성
2. PATCH /v1/{channel-name}/:id — 발행 보고 수정 (부분 업데이트)
3. DELETE /v1/{channel-name}/:id — 발행 보고 삭제 (소프트 삭제)

---

### <span id="채널-발행-통합-조회">📋 채널 발행 통합 조회</span>

**설명**
병원별 전체 채널 발행 데이터를 한 번에 조회하는 통합 API를 추가했습니다. 부서별 멤버 필터, 병원 이름 검색, 커서 페이지네이션을 지원합니다.

**사용 방법**
1. GET /v1/channel-publications/?yearMonth=2026-04&departmentId=4&limit=20
2. 응답에 병원별 channelQuantities(패키지 수량), publications(발행 목록), contentPlanItems(미발행 기획 아이템) 포함

---

### <span id="데일리카드-필드-추가">📋 데일리카드 필드 추가</span>

**설명**
10개 발행 보고 테이블(naver_blog_posts + 9개 신규)에 dailyCard boolean 필드를 추가했습니다. 기본값은 false이며, 기존 PATCH API로 단독 수정 가능합니다.

---

### <span id="기획-아이템-연동">📋 기획 아이템 연동</span>

**설명**
channel-publications 통합 조회 응답에 미발행 기획 아이템(channelType, keyword, topic 등)을 포함하도록 했습니다. 또한 blogId 없이 hospitalId + publishDate만으로 기획 아이템을 조회하는 API를 추가했습니다.

**사용 방법**
1. GET /v1/content-plan-items/by-hospital-date?hospitalId=X&publishDate=Y — naver_blog 제외 채널의 기획 아이템 조회

---

### <span id="plan-상태-변경-버그-수정">📋 plan 상태 변경 버그 수정</span>

**설명**
기획안 상태 일괄 변경 시 이미 발행 완료(published)된 아이템까지 상태가 덮어씌워지던 버그를 수정했습니다. published 상태 아이템은 일괄 변경에서 제외됩니다.

---

### <span id="http-로깅-개선">📋 HTTP 로깅 개선</span>

**설명**
POST/PATCH/DELETE 요청이 성공(200/201)해도 request body가 로그에 찍히지 않던 문제를 수정했습니다. 민감 정보(password, token 등)는 자동 마스킹됩니다.

---

### <span id="당근-매크로-안정화">📋 당근 매크로 안정화</span>

**설명**
당근 사이트 UI 변경에 맞춰 CSS 셀렉터를 수정하고, Gemini API 호출에 재시도 로직(지수 백오프)을 추가했습니다. 스크린샷 iframe 복원 로직을 개선하고, 불안정한 매크로 재시도 로직을 제거했습니다.
