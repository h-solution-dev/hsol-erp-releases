## <span id="마케팅당근-자동화-한눈에-보기-비개발자용">마케팅·당근 자동화 업무 흐름 (비개발자용)</span>

본 절에서는 메뉴 및 일정 기준으로 자동화 동작을 요약합니다. 블로그 포스트 수집·등록은 **마케팅 발행 관리 → 네이버 블로그**에서 처리되며, 당근마켓 소식 발행은 해당 등록 데이터를 입력으로 수행됩니다.

### 변경 전

- **마케팅 발행 관리 → 네이버 블로그**: 게시 글의 URL·제목 등은 사용자가 직접 입력하였습니다.
- **건강정보**: 평일 오전 11시 당근 매크로 실행 시 당근마켓 소식을 발행하였습니다.
- **진료일정**: 네이버 블로그 게시 후 시스템 반영 시 즉시 자동화로 당근마켓 소식을 발행하였습니다.

### 변경 후

**건강정보 (키워드 기획 연동)**

1. 평일 오전 9시 10분: 키워드 기획(발행일·키워드)에 매칭되는 병원 블로그에 접속합니다.
2. 매크로가 URL·제목 등을 수집·파싱하여 마케팅 발행 관리 → 네이버 블로그에 자동 반영합니다.
3. 평일 오전 11시: 당근 매크로가 동일 데이터를 사용하여 당근마켓 소식을 발행합니다.

**진료일정**

1. 매월 18일~익월 10일 구간 내 평일 오후 5시: 시스템에 진료일정 포스트가 미등록된 병원 블로그를 선별합니다.
2. 매크로가 해당 블로그에서 진료일정 게시 여부를 확인합니다.
3. 게시가 확인되면 마케팅 발행 관리 → 네이버 블로그에 진료일정 유형으로 저장합니다.
4. 수집·저장 완료 후 당근마켓 소식 발행 자동화를 연속 수행합니다.

> **참고**: 당근 자동화 미사용으로 설정된 블로그는 진료일정이 저장되어도 당근 발행 대기열에 포함하지 않습니다. 구현 상세는 본 문서 **v1.1.2 상세** 항목을 참고하십시오.

## v1.1.2 상세

### <span id="진료일정-이벤트당근-큐-iskarrottarget-전달">진료일정 이벤트·당근 큐 `isKarrotTarget` 전달</span>

**설명**  
진료일정 타입 네이버 포스트가 저장·갱신될 때 발행하는 `ScheduleGuideBlogPostPersistedEvent`에 `isKarrotTarget`을 실어 보냅니다. `ScheduleGuideBlogPostPersistedHandler`는 이 값만 보고 `karrot_schedule_guide_upload_queue` 적재 여부를 결정합니다.

키워드 기획 매크로와 §0.5 진료일정 매크로는 `findAllActiveNaverBlogChannelsForMacro` 등으로 이미 `naverBlog`를 로드하므로, 해당 플래그를 `BlogVisitTarget`·`ScheduleGuideMacroTargetRow`·`MacroVisitTarget` → `CreateNaverBlogPostDto`로 이어져 `NaverBlogPostsService.create`까지 전달합니다. 전달된 경우 이벤트 발행 직전의 `naver_blogs` 추가 조회가 없습니다.

REST API 등으로 포스트만 생성하는 경로에서는 DTO에 `isKarrotTarget`을 보내지 않을 수 있으므로, 값이 없을 때만 기존과 같이 `blogId` 기준 조회로 보완하여 당근 타겟 블로그의 큐 적재 동작을 유지합니다.

**업무 영향**  
진료일정이 마케팅 발행 관리 → 네이버 블로그에 저장된 뒤 당근 발행 단계로 전달될 때, 당근 자동화 사용으로 설정된 블로그만 발행 대기열에 적재되도록 변경하였습니다. 당근 자동화 미사용 블로그는 DB 저장만 수행되며 당근 발행 대기열에는 포함되지 않습니다.

## v1.1.1 상세

### <span id="자동화-로그-automation_kind-추가">자동화 로그 automation_kind 추가</span>

**설명**  
`platform_automation_logs`에 `automation_kind` 컬럼을 추가했습니다. 자동화 시나리오를 구분하기 위해 `KARROT_NAVER_BLOG_UPLOAD`, `KEYWORD_PLAN_BLOG_VISIT` ENUM을 정의했고, 당근 업로드 로깅 시 `automationKind: KARROT_NAVER_BLOG_UPLOAD`가 저장되도록 반영했습니다.
