## Summary of Changes

이번 릴리스에서 추가·변경된 주요 내용입니다.

| 구분       | 내용                                                                                         |
| :--------- | :------------------------------------------------------------------------------------------- |
| **기획안** | 콘텐츠 기획안/아이템 `status` 컬럼 NOT NULL 전환, 미설정 시 `planning_scheduled` 기본값 적용 |
| **기획안** | 상태 코드 → 한글 라벨 매핑 제거 (표시용 라벨은 프론트에서 처리)                              |
| **병원**   | 병원 메모 스키마를 JSON 형태로 변경                                                          |
| **당근**   | 진료일정·건강정보 당근 프롬프트 줄바꿈 처리 수정                                             |
| **기타**   | 키워드 기획·마케팅 발행보고 관련 API/버그 수정                                               |

## <span id="기획안-status-not-null-및-기본값">기획안 status NOT NULL 및 기본값</span>

**설명**  
`content_plans` / `content_plan_items` 의 `status` 컬럼을 NOT NULL로 변경했습니다. .

---

## <span id="기획안-상태-라벨-매핑-제거">기획안 상태 라벨 매핑 제거</span>

**설명**  
상태 코드(enum) → 한글 표시 문자열 매핑을 백엔드에서 제거했습니다. API는 enum 값만 내려주고, 표시용 라벨은 프론트에서 처리하도록 변경했습니다.

---

## <span id="병원-메모-스키마-json-변경">병원 메모 스키마 JSON 변경</span>

**설명**  
병원 메모 필드를 JSON 형태 스키마로 변경했습니다. `hospital_memo`, `keywords_memo` 등 구조화된 메모 데이터를 저장·조회할 수 있습니다.

---

## <span id="진료일정건강정보-당근-프롬프트-줄바꿈-처리-수정">진료일정·건강정보 당근 프롬프트 줄바꿈 처리 수정</span>

**설명**  
당근마켓 뉴스 생성 시 사용하는 진료일정·건강정보 관련 프롬프트에서 줄바꿈 처리를 수정했습니다.
