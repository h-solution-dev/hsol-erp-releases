## <span id="당근-워커-프로세스-및-스케줄-구조-개선">당근 워커 프로세스 및 스케줄 구조 개선</span>

**설명**  
당근 업로드 실행 경로를 워커 프로세스 기반으로 정리하고, 스케줄 트리거/실행 흐름을 개선했습니다. 장시간 작업이 메인 서버와 분리되어 실행되도록 구성해 안정성을 높였습니다.

---

## <span id="당근-업로드-로직-구조-개선">당근 업로드 로직 구조 개선</span>

**설명**  
당근 업로드 로직을 업로드 대상 조회, 콘텐츠 최적화, 실행, 로깅 등으로 분리했습니다. 기존에 한 서비스에 모여 있던 책임을 나누어 유지보수성과 확장성을 높였습니다.

---

## <span id="역할권한-기반-접근-제어-추가">역할·권한 기반 접근 제어 추가</span>

**설명**  
`@Roles`, `@RequireAuthorities`, `@CheckSameDepartment` 기반 접근 제어를 추가하고, 외부 사용자에 대해서는 작가팀 여부를 별도 가드로 검사하도록 구성했습니다. 관리자 전용/팀리더 전용/외부 작가 전용 API 제어를 보다 명확하게 처리할 수 있습니다.

---

## <span id="외부작가용-네이버-블로그-키워드-조회-api-추가">외부·작가용 네이버 블로그 키워드 조회 API 추가</span>

**설명**  
현재 사용자 담당 병원 기준으로 네이버 블로그 키워드와 병원별 `external_keywords_memo` 를 조회하는 API를 추가했습니다. 외부 인원은 작가팀 소속일 때만 접근할 수 있도록 제어했습니다.

---

## <span id="병원-외주-키워드-메모-전용-수정-api-추가">병원 외주 키워드 메모 전용 수정 API 추가</span>

**설명**  
병원 `memo` JSON 컬럼 내 `external_keywords_memo` 만 수정하는 전용 API를 추가했습니다. 기존 메모 구조는 유지한 채 외주 키워드 메모만 안전하게 병합 저장하도록 구현했습니다.
